## 📂 Programs

Some of the programs in this repository include:

- `ArithmeticOperations.java` — Basic arithmetic operations
- `SumOfThreeNumbers.java` — Calculates the sum of three numbers
- `DivisibilityChecker.java` — Checks divisibility
- `HighestMarkFinder.java` — Finds the highest mark
- `StudentArray.java` — Works with student data using arrays
- `StudentAttendanceCounter.java` — Counts student attendance
- `EmployeeConstructorDemo.java` — Demonstrates constructors
- `MethodOverloading.java` — Demonstrates method overloading
- `AdditionOverloading.java` — Demonstrates overloaded methods
- `EvenNumberFilter.java` — Filters even numbers
- `ElectricityConsumptionChecker.java` — Checks electricity consumption
- `StudentInfo.java` — Stores and displays student information
